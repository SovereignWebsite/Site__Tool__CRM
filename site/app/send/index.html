Requests to the CRM's keeper

Ask the CRM's keeper agent for something: a change, a workflow, a set of drafts, a bug. Your request is sealed to the keeper and signed with your own key, which stays in this browser. The keeper acts within its policy and answers here; only this browser can read the answer.

The CRM's inbox is not set up yet, so requests cannot be sent from here. It needs the keeper's inbox and your key, which are being arranged.

Add your key

Open the key link you were given, paste it here, or paste, drop or scan its QR code.
